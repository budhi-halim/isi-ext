Portal Workspace

Version information loading

A consistent portal interface, useful record previews and a protected saved copy for when you cannot get online.

Download
Features and everyday use
  • Portal interface. Light and dark themes, responsive navigation, clearer forms and consistent tables. On supported list pages, the table scrolls while search, filters and page controls stay in place.
  • Product previews. Hover or focus supported Sample and TIR rows to see available product names and codes without opening every record.
  • Form helpers. Character counts and limits, sample quantity formatting, price helpers, improvement loading and submission progress. Check the final portal status after saving a request.
  • Documents. Download available documents with descriptive filenames. Open files already saved in the offline copy without another portal request.
  • Notifications. Read current notices in the portal, dismiss finished ones and mute supported reminders. Popup notices clear automatically.
  • Offline records. Browse saved Sample Requests, TIR, Stock Requests, Sales Orders, Product List, Product Availability, Stock By Product, Stock Outstanding, Stock History, Stock Adjustment & Auction, Delivery Orders, Returns & Replacement and Sudden Requests.
  • Offline access. Sign in to the online portal with this extension enabled to prepare your account. Open Open saved offline copy in the popup, then unlock it with your portal username and saved password. Use Lock when finished.
  • Background saving. Lists, details and available files fill in gradually and resume when the portal is reachable. Saved times and missing details remain visible. The copy is read only; creating, editing and submitting records still requires the online portal.
  • Connection recovery. An unreachable portal can open the saved copy automatically. Background saving pauses during an outage and resumes after the connection is confirmed.
  • Account settings. Enabled is the main switch. Expand Advanced settings to manage Keep session active, saved records, document files and local storage. Preferences belong to the signed-in account.

Revenue Extractor

Version information loading

Collect delivery records and related sales data for a selected month range, then download an Excel workbook.

Download
Features and everyday use
  • Choose a period. Sign in to the online portal, open the extension and choose the first and last month to extract.
  • Two-stage progress. Follow Delivery Records, then Sales Data. The dashboard shows the current step, progress and an expandable activity log.
  • Revenue workbook. Download sales-order references, branch, salesperson, customer, product, quantity, exchange rate and price information, with the established IDR/USD revenue formulas.
  • Download recovery. If the workbook download fails after extraction, use the workbook download control to try again while the results remain open.
  • Working view. The dashboard stays within the window, with the activity log scrolling inside it. Keep the dashboard open until extraction and download finish.

AutoFeedback

Version information loading

Process older, uncancelled Sample Requests whose feedback is still blank, using the text you choose.

Download
Features and everyday use
  • Set the cutoff. Choose how many days old requests must be. The default is 180 days; eligible requests are processed oldest first.
  • Choose the text. Set Default Komentar (comments) and Default Saran (suggestions). Both are required and saved for the next run.
  • Know what is submitted. Starting a run saves feedback in the live portal. It uses today's sample receipt date and the conclusion Not OK — improvement needed, together with your comments and suggestions.
  • Watch the work. The extension opens or reuses an Islandsun tab and displays request/item progress with the company form.
  • Stop when needed. Stop prevents further actions; feedback already submitted is retained. Closing or reloading the working tab interrupts the run. Check saved feedback before starting again.

First-time setup

Install each extension separately. These downloads are ZIP files for manual installation, not browser-store listings.

  1. Download and extract. Download an extension above. In File Explorer, right-click the ZIP and select Extract All. Keep the extracted folder in a permanent location, such as a folder named Islandsun Extensions in Documents.
  2. Open the extension manager. Copy the address for your browser below, paste it into the address bar and press Enter.

Google Chrome

chrome://extensions

Microsoft Edge

edge://extensions
  1. Enable Developer mode. Turn on the switch on the extension manager page.
  2. Load the folder. Click Load unpacked. Select the extracted extension folder that directly contains manifest.json, then choose Select Folder. Do not select the ZIP or a parent folder containing several extensions.
  3. Pin and open. Use your browser's Extensions menu to pin or show the extension in the toolbar. Click its icon to open it.
  4. Sign in online. Open the Islandsun portal and sign in there. Refresh an existing portal tab once after installing Portal Workspace. Open the extension popup again to check its status.

Official installation guidance: Google Chrome · Microsoft Edge.

Update an installed extension

Finish any active submission or extraction before updating. Update reminders link back to this page; downloaded extensions are updated manually.

  1. Download and extract the latest ZIP for the same extension.
  2. Copy its contents into the same folder you originally loaded, replacing the existing files. Keep that folder's location and name.
  3. Open your browser's extension manager and click Reload on the extension's card. Check that its version matches the download shown above.
  4. Refresh the online portal and any open extension pages once. Open the popup to confirm the extension is enabled.

Use Reload to update. Removing and reinstalling an extension can erase its saved settings and offline copies.

Help with setup

“Manifest file is missing or unreadable”

Open the extracted folder and find manifest.json. Select that exact folder with Load unpacked. If it is missing, extract the ZIP again; do not move individual files out of the extension folder.

The popup asks me to sign in

Sign in on the online Islandsun portal, then reopen the popup or choose Check again. Offline unlock only opens saved records; it does not sign you in to the server.

The offline copy has missing records or files

Background saving needs an available portal and a signed-in account. Keep Save offline records enabled in Advanced settings, and enable Save document files for attachments. Archive coverage and storage in the saved copy shows what has been saved. A missing attachment may not have been uploaded to the live portal.

My password does not unlock the saved copy

Use the password last confirmed by this extension during an online sign-in. After changing your portal password, sign in online with Portal Workspace enabled to update the saved account. Offline unlock cannot reset your portal password.

Developer mode or Load unpacked is unavailable

A company-managed browser may restrict manual extensions. Ask your IT team whether these extensions may be installed on that browser.
